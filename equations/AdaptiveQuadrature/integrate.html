integrate

integrate method

  1. @override
({List<double> guesses, double result}) integrate()
override

Calculates the numerical value of the definite integral of function between lowerBound and upperBound. Returns a record whose fields are:

  • guesses, the values computed by the algorithm to get the result. Their meaning depends on the algorithm: interval-based methods store the values of function at the points they sample, while AdaptiveQuadrature stores the integral of each subinterval it accepts;

  • result, the approximate value of the integral on the interval [lowerBound, upperBound].

If lowerBound is greater than upperBound, the sign of the result is reversed, as in the standard convention for definite integrals.

Throws a NumericalIntegrationException if lowerBound or upperBound is not finite.

The guesses list contains the integral of each subinterval accepted by the algorithm, in order from lowerBound to upperBound. Its elements add up to result (up to rounding errors). If lowerBound is equal to upperBound, the list is empty and result is 0.

Also throws a NumericalIntegrationException if the algorithm doesn't converge within maxDepth subdivisions, or if the function isn't finite somewhere in the interval.

Implementation

@override
({List<double> guesses, double result}) integrate() {
  if (!lowerBound.isFinite || !upperBound.isFinite) {
    throw const NumericalIntegrationException(
      'The integration bounds must be finite.',
    );
  }

  final width = upperBound - lowerBound;

  if (width == 0) {
    return (guesses: <double>[], result: 0.0);
  }

  final points = [
    lowerBound,
    ..._initialPartition.map((t) => lowerBound + t * width),
    upperBound,
  ];
  final values = points.map(evaluateFunction).toList(growable: false);

  // A rough estimate of the integral of |f(x)|, using the trapezoidal rule on
  // the initial subintervals. The tolerance is relative to this value.
  var scale = 0.0;
  for (var i = 0; i < points.length - 1; ++i) {
    final step = (points[i + 1] - points[i]).abs();
    scale += step * (values[i].abs() + values[i + 1].abs()) / 2;
  }

  if (!scale.isFinite) {
    throw NumericalIntegrationException(
      'The function is not finite on the interval [$lowerBound, '
      '$upperBound].',
    );
  }

  final reference = scale > 0 ? scale : 1;
  final tolerance = _relativeTolerance * reference;
  final minimumTolerance = _minimumRelativeTolerance * reference;

  final guesses = <double>[];
  var result = 0.0;

  for (var i = 0; i < points.length - 1; ++i) {
    final a = points[i];
    final b = points[i + 1];

    result += _adaptive(
      a: a,
      b: b,
      fa: values[i],
      fb: values[i + 1],
      fc: evaluateFunction((a + b) / 2.0),
      tolerance: tolerance * ((b - a) / width).abs(),
      minimumTolerance: minimumTolerance,
      depth: 0,
      guesses: guesses,
    );
  }

  return (
    guesses: guesses,
    result: result,
  );
}

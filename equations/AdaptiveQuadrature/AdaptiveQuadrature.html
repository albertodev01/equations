Adaptive quadrature is a technique for approximating the value of a definite integral that automatically adjusts the step size based on the local behavior of the function being integrated. This class implements the adaptive Simpson's method.

Details

Unlike fixed-step methods such as SimpsonRule or TrapezoidalRule, adaptive quadrature:

  • uses smaller step sizes in regions where the function varies rapidly;
  • uses larger step sizes in regions where the function is smooth;
  • automatically determines how to subdivide the integration interval;
  • usually reaches a given accuracy with fewer function evaluations.

The algorithm first splits [lowerBound, upperBound] into a few subintervals of different widths, so that the function isn't only sampled at evenly spaced points (which could all be zeros of a periodic function, for example). Then, on each subinterval, it:

  1. computes two Simpson's rule approximations, one with a single step and one with two steps;
  2. compares their difference to a tolerance;
  3. if the difference is small enough, accepts the two-step approximation, improved with Richardson extrapolation;
  4. if not, splits the subinterval in half and applies the method to both halves, each with half of the tolerance.

The tolerance is relative to the size of the integral: the algorithm aims for an error of at most about 10^-12 times an estimate of the integral of |f(x)| on [lowerBound, upperBound].

This approach makes adaptive quadrature particularly effective for functions with varying smoothness or regions of high curvature.

Both lowerBound and upperBound must be finite. Each initial subinterval is split at most maxDepth times. If the approximations don't converge by then (for example, near a singularity such as 1/x around 0), or if the function isn't finite somewhere in the interval, integrate throws a NumericalIntegrationException.

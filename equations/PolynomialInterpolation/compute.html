Evaluates the Lagrange interpolation polynomial at the given point x.

This method uses the barycentric form of Lagrange's formula, which is numerically more stable than evaluating each Lagrange basis polynomial L_i(x) separately:

w_i  = 1 / ((x_i - x_0) * ... * (x_i - x_(n-1)))   (skipping j = i)
p(x) = sum(w_i * y_i / (x - x_i)) / sum(w_i / (x - x_i))

Each call costs O(n^2) operations, where n is the number of nodes. To evaluate the same interpolation at many points, consider calling buildPolynomial once and evaluating the returned Algebraic instead.

Implementation

@override
double compute(double x) {
  _validateNodes();

  for (final node in nodes) {
    if (x == node.x) {
      return node.y;
    }
  }

  var numerator = 0.0;
  var denominator = 0.0;

  for (var i = 0; i < nodes.length; i++) {
    var weight = 1.0;
    for (var j = 0; j < nodes.length; j++) {
      if (i != j) {
        weight /= nodes[i].x - nodes[j].x;
      }
    }

    final term = weight / (x - nodes[i].x);
    numerator += term * nodes[i].y;
    denominator += term;
  }

  return numerator / denominator;
}

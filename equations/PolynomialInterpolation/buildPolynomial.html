Algebraic buildPolynomial()

Computes the interpolation polynomial and returns it as an Algebraic object.

The polynomial is built in two steps, both costing O(n^2) operations and O(n) memory, where n is the number of nodes:

  1. The divided differences c_k = f[x_0, ..., x_k] are computed, so that the polynomial in Newton form is p(x) = c_0 + (x - x_0)(c_1 + (x - x_1)(c_2 + ...)).
  2. The Newton form is expanded from the innermost term outwards, which gives the coefficients of x^0, x^1, ..., x^(n-1).

No linear system is solved, which is both faster and more accurate than solving the Vandermonde system with a general purpose solver.

Even so, representing a polynomial by its coefficients becomes ill-conditioned for large numbers of nodes (more than 15-20): small changes in the data can produce large changes in the coefficients. For large datasets, consider using SplineInterpolation instead.

Implementation

Algebraic buildPolynomial() {
  _validateNodes();
  final n = nodes.length;

  // Divided differences, computed in place: c[k] = f[x_0, ..., x_k]
  final c = nodes.map((node) => node.y).toList(growable: false);
  for (var k = 1; k < n; k++) {
    for (var i = n - 1; i >= k; i--) {
      c[i] = (c[i] - c[i - 1]) / (nodes[i].x - nodes[i - k].x);
    }
  }

  // Expanding the Newton form from the innermost term outwards. At each
  // step q(x) becomes q(x) * (x - x_k) + c[k]. The value a[j] is the
  // coefficient of x^j.
  final a = List<double>.filled(n, 0)..first = c.last;
  for (var k = n - 2; k >= 0; k--) {
    final xk = nodes[k].x;
    for (var j = n - 1 - k; j >= 1; j--) {
      a[j] = a[j - 1] - xk * a[j];
    }
    a.first = c[k] - xk * a.first;
  }

  // Algebraic expects the coefficients from the highest degree to the lowest
  final coefficients = a.reversed.toList(growable: false);

  return Algebraic.fromReal(_trimLeadingCoefficients(coefficients));
}

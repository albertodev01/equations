Implements Ridders' method to find the roots of a given equation.

It's a modification of the false position method that uses exponential interpolation: on each step, the function is evaluated at the midpoint of the interval and the three points are mapped onto a straight line with an exponential factor. The root of that line is the new guess.

  • The method requires the root to be bracketed between two points a and b, so f(a) and f(b) must have opposite signs. If f(a) or f(b) is zero, that endpoint is returned as the root.

  • The convergence is guaranteed for continuous functions when the root is properly bracketed, making it more reliable than methods like Newton's method for ill-behaved functions. The new guess is always inside the interval.

  • The rate of convergence is quadratic. Each step evaluates the function twice, so the efficiency index is sqrt(2): faster than bisection but slower than Newton's method.

  • The algorithm stops when |f(x)| or the width of the interval that contains the root is smaller than tolerance.

Solves an inequality in the form P(x) < 0, P(x) <= 0, P(x) > 0 or P(x) >= 0, where P(x) is a polynomial with real coefficients.

Algorithm Overview

The sign of P(x) can only change at its real roots, so the roots split the real line into regions where the sign of P(x) is constant:

  1. The real part of every root of P(x) is a boundary between two regions. This includes complex roots, because a real root computed numerically can have a small imaginary part (for example, the roots of (x - 2)^5). A boundary that is not a real root has the same sign on both sides, so it disappears in step 4.
  2. A boundary is a root when P(x) is zero up to precision, relative to the size of the terms of P(x).
  3. The sign of P(x) is tested once inside each region. Roots that are only separated by values of P(x) that are zero up to floating point rounding are merged into a single root.
  4. Consecutive regions and boundaries where the inequality holds are joined, so the returned solutions never touch each other.

Example

final solver = AlgebraicInequalitySolver(
  // (x - 1)^2 * (x - 3)
  polynomial: Algebraic.fromReal([1, -5, 7, -3]),
  inequalityType: AlgebraicInequalityType.lessThanOrEqualTo,
);

final solutions = solver.solve();
// [AlgebraicInequalitySmallerThan(value: 3, isInclusive: true)]

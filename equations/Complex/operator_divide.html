Complex operator /(
  1. Complex other

Divides two complex numbers.

It uses Smith's algorithm, which avoids the overflow and the underflow of the textbook formula (a + bi)(c - di) / (c^2 + d^2) when the parts of other are very large or very small.

Like the division of two double values, dividing by zero doesn't throw: the result has NaN parts. Use reciprocal to get an exception instead.

Implementation

Complex operator /(Complex other) {
  final c = other.real;
  final d = other.imaginary;

  if (c.abs() >= d.abs()) {
    final ratio = d / c;
    final den = c + d * ratio;

    return Complex(
      (real + imaginary * ratio) / den,
      (imaginary - real * ratio) / den,
    );
  }

  final ratio = c / d;
  final den = c * ratio + d;

  return Complex(
    (real * ratio + imaginary) / den,
    (imaginary * ratio - real) / den,
  );
}

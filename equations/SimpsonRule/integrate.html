integrate

integrate method

  1. @override
({List<double> guesses, double result}) integrate()
override

Calculates the numerical value of the definite integral of function between lowerBound and upperBound. Returns a record whose fields are:

  • guesses, the values computed by the algorithm to get the result. Their meaning depends on the algorithm: interval-based methods store the values of function at the points they sample, while AdaptiveQuadrature stores the integral of each subinterval it accepts;

  • result, the approximate value of the integral on the interval [lowerBound, upperBound].

If lowerBound is greater than upperBound, the sign of the result is reversed, as in the standard convention for definite integrals.

Throws a NumericalIntegrationException if lowerBound or upperBound is not finite.

The guesses list contains the values of function at the points x_i = lowerBound + i * h, for i = 0, 1, ..., intervals, so it has intervals + 1 elements.

Also throws a NumericalIntegrationException if intervals is not positive or odd.

Implementation

@override
({List<double> guesses, double result}) integrate() {
  if (!lowerBound.isFinite || !upperBound.isFinite) {
    throw const NumericalIntegrationException(
      'The integration bounds must be finite.',
    );
  }
  if (intervals <= 0) {
    throw const NumericalIntegrationException(
      'The number of intervals must be positive.',
    );
  }
  if (intervals % 2 != 0) {
    throw const NumericalIntegrationException(
      'The number of intervals must be even.',
    );
  }

  final h = (upperBound - lowerBound) / intervals;

  // Initialize sums for the Simpson's Rule formula
  // oddSum: sum of f(x) at odd-indexed points (multiplied by 4)
  // evenSum: sum of f(x) at even-indexed points (multiplied by 2)
  var oddSum = 0.0;
  var evenSum = 0.0;
  final guesses = List<double>.filled(intervals + 1, 0);

  for (var i = 1; i < intervals; i += 2) {
    final x = lowerBound + i * h;
    final fx = evaluateFunction(x);
    oddSum += fx;
    guesses[i] = fx;
  }

  for (var i = 2; i < intervals - 1; i += 2) {
    final x = lowerBound + i * h;
    final fx = evaluateFunction(x);
    evenSum += fx;
    guesses[i] = fx;
  }

  final fLower = evaluateFunction(lowerBound);
  final fUpper = evaluateFunction(upperBound);
  guesses[0] = fLower;
  guesses[intervals] = fUpper;

  return (
    guesses: guesses,
    result: (fLower + 4 * oddSum + 2 * evenSum + fUpper) * h / 3,
  );
}

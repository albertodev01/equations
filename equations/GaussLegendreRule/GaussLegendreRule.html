The Gauss-Legendre rule is a numerical integration technique that splits the integration interval into subintervals and, on each of them, evaluates the function at the roots of a Legendre polynomial (the Gauss points), multiplied by specific weights.

The Gauss points are strictly inside each subinterval, so the function is never evaluated at lowerBound or upperBound. For this reason, this method also works when the function isn't finite at the bounds (such as 1/sqrt(x) on [0, 1]), although it converges slowly in that case.

This algorithm requires the intervals parameter, which must be positive, and the points parameter, which must be between 1 and 5.

By default, intervals is set to 10 and points is set to 3, so the function is evaluated 30 times.

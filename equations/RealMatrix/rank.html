  1. @override
int rank()

The rank of a matrix A is the dimension of the vector space generated by its columns. This corresponds to the maximal number of linearly independent columns of A.

The rank is generally denoted by rank(A) or rk(A). The rank of a matrix is equal to the rank of its transpose, and it cannot exceed the minimum of the number of rows and columns.

The rank is computed with Gaussian elimination and partial pivoting. Pivots that are negligible compared to the magnitude of the matrix elements are treated as zeros, so that rounding errors don't increase the rank.

Implementation

@override
int rank() {
  final tolerance = _pivotTolerance();
  final m = rowCount;
  final n = columnCount;
  final a = toList();
  var rank = 0;

  for (var col = 0; col < n && rank < m; ++col) {
    var pivotRow = rank;
    for (var i = rank + 1; i < m; ++i) {
      if (a[n * i + col].abs() > a[n * pivotRow + col].abs()) {
        pivotRow = i;
      }
    }

    if (a[n * pivotRow + col].abs() <= tolerance) {
      continue;
    }

    _swapRows(a, n, rank, pivotRow);
    final pivot = a[n * rank + col];
    for (var i = rank + 1; i < m; ++i) {
      final factor = a[n * i + col] / pivot;
      for (var j = col; j < n; ++j) {
        a[n * i + j] -= factor * a[n * rank + j];
      }
    }

    ++rank;
  }

  return rank;
}

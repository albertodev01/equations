Concrete implementation of Algebraic that approximates all roots of a polynomial of any degree using the Durand-Kerner (Weierstrass) method.

For polynomials of degree 4 or lower, consider using Quartic, Cubic, Quadratic or Linear instead, as they compute the roots with closed-form formulas.

By the Abel-Ruffini theorem, there is no general formula in radicals for the roots of a polynomial of degree 5 or higher, so this class returns numerical approximations of the roots.

The method needs one starting point per root. You can provide them with initialGuess, which must then contain exactly degree values. If initialGuess is empty, the starting points are placed on a circle around the centroid of the roots, as suggested by Aberth, whose radius is an upper bound for the distance of the roots from the centroid. If you are not sure which starting points to provide, leave initialGuess empty.

The method converges for almost all starting points in practice, but convergence is not guaranteed in general. If the roots don't converge within maxSteps iterations, the current approximations are returned.

These are examples of generic algebraic equations, where the coefficient with the highest degree goes first:

// P(x) = x^5 - 3x^4 + 2x^2 - x + 7
final genericAlgebraic1 = GenericAlgebraic.realEquation(
  coefficients: [1, -3, 0, 2, -1, 7],
);

// P(x) = (3 + 8i)x^6 - 2x^5 + (-1 + 5i)x^3 + 6x + i
final genericAlgebraic2 = GenericAlgebraic(
  coefficients: [
    Complex(3, 8),
    Complex.fromReal(-2),
    Complex.zero(),
    Complex(-1, 5),
    Complex.zero(),
    Complex.fromReal(6),
    Complex.i(),
  ],
);

// P(x) = x^5 - 1, starting from custom initial guesses
final genericAlgebraic3 = GenericAlgebraic.realEquation(
  coefficients: [1, 0, 0, 0, 0, -1],
  initialGuess: [
    Complex.fromReal(2),
    Complex(1, 1),
    Complex(-1, 1),
    Complex(-1, -1),
    Complex(1, -1),
  ],
);

If the coefficients of your polynomial contain only real numbers, consider using the GenericAlgebraic.realEquation constructor instead.

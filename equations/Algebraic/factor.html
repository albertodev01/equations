factor method

List<Algebraic> factor()

Factors the polynomial over the complex numbers.

Every non-constant polynomial with complex coefficients can be written as a(x - r1)(x - r2)...(x - rn), where a is the leading coefficient and r1, ..., rn are the roots. This method returns those factors:

  • a Constant holding the leading coefficient a, as the first element, but only when a is not 1;
  • one monic Linear factor (x - ri) for each root, in the order returned by solutions. A root with multiplicity k appears k times.

The product of the returned factors is always equal to this polynomial (up to the precision of solutions). For example:

final poly1 = Algebraic.fromReal([1, 0, -4]); // x^2 - 4
final factors1 = poly1.factor();
// [x - 2, x + 2]

final poly2 = Algebraic.fromReal([2, 0, -8]); // 2x^2 - 8
final factors2 = poly2.factor();
// [2, x - 2, x + 2]

final poly3 = Algebraic.fromReal([1, 0, 4]); // x^2 + 4
final factors3 = poly3.factor();
// [x - 2i, x + 2i]

If the polynomial is a Constant, it has no roots and a list containing only this polynomial is returned.

For polynomials of degree 5 or higher, the roots are computed with a numerical method, so the linear factors are approximations.

Implementation

List<Algebraic> factor() {
  final roots = solutions();

  // Only constants have no roots (fundamental theorem of algebra).
  if (roots.isEmpty) {
    return [this];
  }

  final leadingCoefficient = coefficients.first;

  return [
    if (leadingCoefficient != const Complex.fromReal(1))
      Constant(a: leadingCoefficient),
    ...roots.map((root) => Linear(b: -root)),
  ];
}

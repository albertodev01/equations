Solves the inequality associated with this polynomial.

The inequality type is specified by the inequalityType parameter, which can be one of the following (where P(x) represents this polynomial):

  • AlgebraicInequalityType.lessThan: solves P(x) < 0
  • AlgebraicInequalityType.lessThanOrEqualTo: solves P(x) <= 0
  • AlgebraicInequalityType.greaterThan: solves P(x) > 0
  • AlgebraicInequalityType.greaterThanOrEqualTo: solves P(x) >= 0

The precision parameter (defaults to 1e-10) is the relative tolerance used to decide whether a value of x is a root: x is a root when |P(x)| <= precision * S(x), where S(x) is the sum of the absolute values of the terms of P(x). The precision must be a positive number.

Returns a list of AlgebraicInequalitySolution objects representing the intervals where the inequality is satisfied, sorted in ascending order. For <= and >= every returned interval includes its endpoints, while for < and > it excludes them. The returned list can be empty if the inequality is not satisfied for any real number.

The roots are computed with solutions, so for polynomials of degree 5 or higher the endpoints of the intervals are approximations. See AlgebraicInequalitySolver for more details.

Throws an AlgebraicException if:

  • The polynomial has complex coefficients
  • The precision parameter is not positive

Given an equation in the form Ax = b, A is a square matrix containing n equations in n unknowns and b is the vector of the known values. This class can only be built with square matrices.

Solves a system of linear equations using the Jacobi iterative method. The given input matrix, representing the system of linear equations, must be square.

At each step, every component of the solution is computed from the components of the previous step only.

Convergence

The method is guaranteed to converge if the matrix A is strictly diagonally dominant. This is a sufficient condition, not a necessary one: the method may converge for other matrices too. The elements on the main diagonal must not be zero, because every step divides by them.

The solve method stops when the largest change of a component between two steps is at most precision * max(1, m), where m is the largest absolute value of a component. It throws a SystemSolverException if the method diverges or doesn't converge within maxSteps steps.

Example:

final solver = JacobiSolver(
  matrix: RealMatrix.fromData(
    rows: 2,
    columns: 2,
    data: [[4, 1], [1, 3]], // Strictly diagonally dominant
  ),
  knownValues: [5, 4],
  x0: [0, 0],
);

final solution = solver.solve();
// Returns: [1, 1] (approximately)

Parameters:

  • matrix is the matrix containing the equations;
  • knownValues is the vector with the known values;
  • x0 is the initial guess (defaults to the zero vector);
  • precision determines how accurate the algorithm has to be (defaults to 1.0e-10);
  • maxSteps is the maximum number of iterations (defaults to 1000).

Throws a SystemSolverException if:

  • The matrix is not square, or
  • The length of knownValues or x0 doesn't match the matrix size, or
  • The matrix, knownValues or x0 contain NaN or infinite values, or
  • The matrix has a zero on its main diagonal, or
  • maxSteps is smaller than 1.

Given an equation in the form Ax = b, A is a square matrix containing n equations in n unknowns and b is the vector of the known values. This class can only be built with square matrices.

Solves a system of linear equations using the Successive Over-Relaxation (SOR) iterative method.

A theorem due to Kahan (1958) shows that SOR fails to converge if w is not in the (0, 2) range. The optimal value of w depends on the spectral radius of the iteration matrix:

  • For w = 1: SOR reduces to the Gauss-Seidel method
  • For 0 < w < 1: Under-relaxation (slower convergence, more stable)
  • For 1 < w < 2: Over-relaxation (faster convergence when w is close to the optimal value, slower when it's too large)

The method is guaranteed to converge for any w in (0, 2) if the matrix is symmetric positive-definite. The elements on the main diagonal must not be zero, because every step divides by them.

When to use

SOR is particularly effective for:

  • Large, sparse systems
  • Systems with diagonally dominant matrices
  • When you need faster convergence than Gauss-Seidel

Example

final matrix = RealMatrix.fromData(
  rows: 3,
  columns: 3,
  data: [
    [4, -1, 0],
    [-1, 4, -1],
    [0, -1, 4],
  ],
);

final sor = SORSolver(
  matrix: matrix,
  knownValues: [1, 5, 0],
  w: 1.03, // Close to the optimal relaxation factor for this matrix
  precision: 1.0e-10,
  maxSteps: 50,
);

final solution = sor.solve();
// Returns: [0.625, 1.5, 0.375] (approximately)

Parameters:

  • matrix is the matrix containing the equations;
  • knownValues is the vector with the known values;
  • w is the relaxation factor (must be in the (0, 2) range);
  • x0 is the initial guess (defaults to the zero vector);
  • precision determines how accurate the algorithm has to be (defaults to 1.0e-10);
  • maxSteps is the maximum number of iterations (defaults to 1000).

The solve method stops when the largest change of a component between two steps is at most precision * max(1, m), where m is the largest absolute value of a component. It throws a SystemSolverException if the method diverges or doesn't converge within maxSteps steps.

Throws a SystemSolverException if:

  • The matrix is not square, or
  • The length of knownValues or x0 doesn't match the matrix size, or
  • The matrix, knownValues or x0 contain NaN or infinite values, or
  • w is not in the (0, 2) range, or
  • The matrix has a zero on its main diagonal, or
  • maxSteps is smaller than 1.

Implementation

new({
  required super.matrix,
  required super.knownValues,
  required this.w,
  List<double>? x0,
  super.precision,
  this.maxSteps = 1000,
}) : x0 = x0 ?? List<double>.filled(knownValues.length, 0) {
  if (!(w > 0 && w < 2)) {
    throw const SystemSolverException(
      'The relaxation factor w must be in the range (0, 2) for convergence.',
    );
  }

  validateIterativeSolver(matrix: matrix, x0: this.x0, maxSteps: maxSteps);
}

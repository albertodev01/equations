Given an equation in the form Ax = b, A is a square matrix containing n equations in n unknowns and b is the vector of the known values. This class can only be built with square matrices.

Solves a system of linear equations using the LU decomposition method.

The LU decomposition with partial pivoting factors a square matrix A into the product PA = LU, where P is a permutation matrix, L is a lower triangular matrix with ones on the diagonal and U is an upper triangular matrix. This allows the system Ax = b to be solved in two steps:

  1. Forward substitution: Solve Ly = Pb for y
  2. Back substitution: Solve Ux = y for x

The factorization is computed the first time it's needed and then reused, so solveFor can solve other systems with the same matrix (and different known values) in O(n^2) operations instead of O(n^3).

When to Use

LU decomposition is particularly useful when:

  • You need to solve multiple systems with the same coefficient matrix A (see solveFor)
  • The matrix A is not symmetric positive-definite (otherwise, use CholeskySolver)
  • You want a direct method that doesn't require iteration

Requirements

The input matrix must be square (n x n) and non-singular. The solve and solveFor methods throw a SystemSolverException if the matrix is singular or nearly singular.

Example

final solver = LUSolver(
  matrix: RealMatrix.fromData(
    rows: 3,
    columns: 3,
    data: [
      [2, 1, 1],
      [4, -6, 0],
      [-2, 7, 2],
    ],
  ),
  knownValues: [5, -2, 9],
);

final solution = solver.solve();
// Returns: [1, 1, 2]

// Reuses the factorization of the matrix
final other = solver.solveFor([4, -2, 7]);
// Returns: [1, 1, 1]

Parameters:

  • matrix is the matrix containing the equations;
  • knownValues is the vector with the known values;
  • precision determines the tolerance for detecting singular matrices (defaults to 1.0e-10). An element on the diagonal of U is considered zero when its absolute value is at most precision times the largest absolute value in the matrix.

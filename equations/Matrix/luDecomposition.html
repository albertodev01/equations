luDecomposition abstract method

List<Matrix<T>> luDecomposition()

Factors the matrix using the LU decomposition with partial pivoting. In particular, this method returns the L, U and P matrices of the

  • P x A = L x U

relation, where L is a lower triangular matrix with ones on the diagonal, U is an upper triangular matrix and P is the permutation matrix of the row swaps. The matrix must be square.

The returned list contains L at index 0, U at index 1, and P at index 2.

The decomposition always exists, singular matrices included: in that case, at least one element on the diagonal of U is zero (or negligible).

A MatrixException is thrown if the matrix is not square (i.e., if rowCount != columnCount).
